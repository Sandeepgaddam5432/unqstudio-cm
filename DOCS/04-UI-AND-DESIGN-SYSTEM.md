# 04 · UI & Design System

## Tokens (`src/index.css`)
CSS variables drive Tailwind 4 theme colours: `bg`, `panel`, `subtle`, `fg`, `muted`, `faint`, `line`, `line-strong`, `accent`, `accent-fg`, `success`, `warn`, `danger`, `shadow-pop`.
- **Obsidian Dark** (default): near-black `#09090B` surfaces, 1px hairline borders (`border-line`), violet/indigo accent.
- **Paper Light**: warm white surfaces, same hairline rhythm.
- Typography: Inter Variable (UI), JetBrains Mono Variable (code). Micro-transitions: 150ms (`transition-colors duration-150`); popover `animate-pop`, sheet `animate-sheet`, backdrop `animate-fade`.
- Focus: `focus-visible:ring-2 ring-accent/30`; inputs `focus-within:ring-accent/20`.

## Adaptive Dual Workspace
- **Studio Mode** (default): Chat | Preview/Theme/History (`SplitPane`, ratio persisted).
- **Code Mode** (`Ctrl/⌘+E`): file tree · CodeMirror 6 · diff viewer · search · preview.
- `<768px`: single column + **bottom navigation** `Chat | Preview | Code` (`src/ui/workspace/Body.tsx`); Code selects `mode: 'code'`.

## Floating UI anchoring & Mobile Bottom Sheet (`src/ui/primitives/Popover.tsx`)
**v1.0 bug root cause:** the dropdown computed `getBoundingClientRect()` once on open and positioned itself with `position: fixed`; any ancestor scroll/resize moved the trigger but not the panel (it also closed on resize only).
**v2.0 fix:** `@floating-ui/react` `useFloating({ strategy: 'fixed', whileElementsMounted: autoUpdate, middleware: [offset(6), flip, shift, size] })` in a portal. `autoUpdate` subscribes to ancestor scroll, resize, and element resize/layout shift, so the panel tracks its trigger continuously; `size()` caps `max-height`/`max-width` to the available viewport space (never overflows).
Rules:
- `≥640px`: anchored popover. `<640px` with `mobileSheet`: bottom-sheet (backdrop blur, drag-handle, `max-h-[82dvh]`, safe-area padding, body scroll lock, Esc/backdrop dismiss).
- Model picker: sticky search input + provider filter pills + grouped list.

## Chat 3-zone grid (`src/ui/chat/ChatPanel.tsx`)
```
h-[100dvh] (Workspace) ─ TopBar
  └ ChatPanel  grid  grid-rows-[auto_minmax(0,1fr)_auto]  min-w-0 overflow-x-hidden
      ├ zone 1  header      model/token badge · Chat settings · Clear
      ├ zone 2  messages    min-h-0 overflow-y-auto overflow-x-hidden (only scroller)
      └ zone 3  composer    textarea (top) + wrapped toolbar row (below)
```
Composer toolbar (`flex-wrap`): Attach · `@` file · Voice · Enhance ✨ · Rules · Mode | (ml-auto) Model pill · Send/Stop. Wrapping, not overlay, guarantees zero overlap at 375/768/1440px. Long filenames/code truncate or scroll inside their own boxes (`min-w-0`, `[overflow-wrap:anywhere]`).

Chat customization (`useChatPrefs`, key `unq.chatprefs.v1`): density, font size, auto-expand `<think>`, token/cost badges, agent file activity cards, auto-scroll.


## v2.1 — Icon system (`src/ui/icons/`)
Three layers, so an icon can never be a broken image: **(1)** bundled mono `currentColor` SVG glyphs for 35 brands/families (`brandSvgs.ts`, generated by `scripts/gen-brand-svgs.mjs` from the dev-only `@lobehub/icons-static-svg`); **(2)** for long-tail providers a CDN glyph / directory logo that is **preloaded** (`new Image()`, session-memoised) and only rendered as `<img>` once `naturalWidth > 0`; **(3)** a deterministic monogram badge (FNV hash → HSL hue, 2 letters). `ModelIcon` first runs `detectModelFamily()` so `anthropic/claude-*` inside OpenRouter shows Claude. Used by `ModelPill`, `ModelPicker`, `ProvidersTab`, `OnboardingWizard`, the `ChatPanel` header and custom-provider cards.

## v2.1 — Model Picker & Settings hub
**Model Picker** (`src/ui/chat/ModelPicker.tsx`): sticky fuzzy search (`core/ai/modelSearch.ts`: name, id, provider, plus `vision` / `reasoning` / `tools` / `free`), pills `Configured · Favorites ⭐ · Browser-Ready · Custom · Local · All Providers`. Favorites + the last 3 models live in `store/modelPrefs.ts` (`unq.modelPrefs.v1`) and are pinned on top. The list is ONE flat row model (`section | head | model | skeleton | note`) rendered through a fixed-height window (`ROW_H = 36`, overscan 8): only ~25 DOM rows exist regardless of 9k+ models. Search results are capped at 300 and ranked by `scoreModel`.
**Settings hub** (`src/ui/SettingsDrawer.tsx`): left sidebar ≥768px, grouped native `<select>` below. Groups → AI & Models (Providers Hub, Prompt Rules) · Workspace (Chat & Editor, Appearance) · Account (Sign In & Cloud Sync) · Integrations (Connections, Plugins & MCP) · System (Data & Storage, Debug & Logs). Legacy id `general` aliases to `editor`. Providers Hub sections: Add Custom Provider → Vault → Catalog status → Configured & Active → Popular Cloud → Custom Providers → Local AI → All Providers.

## v2.1 — Code Mode inline edit & heal pill
Selecting code shows a floating **AI Edit (⌘K)** button (`data-testid="inline-edit-button"`); `Mod-i` works with or without a selection, `Mod-k` only with a selection (otherwise ⌘K stays the command palette — the CM `keydown` handler calls `stopPropagation` only when it consumes the key). The widget (`data-inline-edit`) is absolutely positioned inside the editor wrapper (`data-code-editor-wrap`). The chat header shows `data-heal-pill` ("Auto-healing build · Attempt n/max", Stop, Undo) — hidden text shrinks to "Healing n/max" below the `@lg` container width so the 375 px header never overflows.


## Preview bridge & Visual Inspector — exact `postMessage` contract
Source of truth: `src/core/runtime/bridgeScript.ts` (injected in the sandboxed iframe) ↔ `src/ui/preview/Preview.tsx` / `bridge.ts` (host). Every message carries `__unq: true` (messages without it are ignored) and is posted with target origin `*` (the iframe has an opaque origin).

| Direction | `type` | Payload | Meaning |
|---|---|---|---|
| iframe → host | `ready` | — | Bridge booted; host answers with `theme` and, if inspect mode is on, `inspect:enable`. |
| iframe → host | `console` | `level`, `args[]` | Forwarded `console.*` call. |
| iframe → host | `error` | `message`, `stack`, `file`, `line`, `column` | Uncaught error / unhandled rejection (feeds “Fix with AI” and Auto-Heal). |
| iframe → host | `resource-error` | `url`, `tag` | A `<script>/<img>/<link>` failed to load. |
| iframe → host | `inspect:select` | `info` (tag, classes, text, rect, computed styles, source hint) | User clicked an element in inspect mode. |
| iframe → host | `screenshot` | `id`, `dataUrl` or `error` | Result of a raster capture. |
| host → iframe | `inspect:enable` | `on: boolean` | Toggle the hover/select overlay (`[data-unq-inspector]`). |
| host → iframe | `inspect:apply` | `edit` | Apply a quick edit live (class / text / colour) without a rebuild. |
| host → iframe | `theme` | `dark: boolean` | Toggle the `dark` class inside the preview. |
| host → iframe | `theme-css` | `css` | Inject/replace the Theme Studio token block live. |
| host → iframe | `screenshot` | `id` | Request a capture; answered with the `screenshot` message above. |

## v3.0 Native mobile shell
- **BottomSheet** (`src/ui/primitives/BottomSheet.tsx`, physics in `sheetPhysics.ts`): used automatically by `Modal`, `Drawer` and `Dropdown mobileSheet` below 768px.
- **Top bar (phone)**: menu · Project Pill (opens `ProjectSwitcher`) · Publish pill. Undo/redo/theme/palette moved into the Project sheet.

## v3.0 Home & sidebar

## v3.0 Chat

Version numbers come from `core/ai/versions.ts`; bookmarks live in `ProjectMeta.bookmarks`. Model Picker rows are `id=mp-row-N`; the search box is an ARIA combobox controlling `#mp-list`.

## v3.0 Preview

## v3.0 Agent steps in chat
